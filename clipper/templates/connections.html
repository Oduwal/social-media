Instagram Reels

{{ badge(status.instagram) }}

Posted automatically. Your Instagram must be a Professional account linked to a Facebook Page.

Set up (free, about 20 minutes)
  1. In the Instagram app: Settings → Account type and tools → Switch to professional account (Creator or Business).
  2. Link it to a Facebook Page you manage (Facebook Page settings → Linked accounts → Instagram). Make a Page if you have none.
  3. Go to developers.facebook.com/apps ↗ → Create app → type Business.
  4. Add the products Facebook Login for Business and Instagram (API setup with Facebook login).
  5. In Facebook Login → Settings, add this Valid OAuth Redirect URI: {{ status.instagram.redirect_uri }} (localhost works while the app stays in Development mode, which is all you need for your own account).
  6. Copy the App ID and App secret (App settings → Basic) below, save, then click Connect Instagram and allow everything it asks.
{{ keyfield("META_APP_ID", "App ID") }}{{ keyfield("META_APP_SECRET", "App secret") }}

X

{{ badge(status.x) }}

Posted automatically. X charges about $0.015 per post ($0.20 if the caption has a link) from prepaid credit.

Set up (about 10 minutes)
  1. Go to developer.x.com ↗, sign in with the X account you post from, and create an app (pay-per-use).
  2. Add a few dollars of credit.
  3. In the app's User authentication settings, set App permissions to Read and write.
  4. Under Keys and tokens, copy the API Key and Secret, then generate and copy the Access Token and Secret (generate them after setting Read and write).
  5. Paste all four below, save, then click Check X keys.
